Spare Parts ERP for Windows
==========================

This portable 64-bit Windows application includes its own Python runtime and
all required packages. Python does not need to be installed separately.

1. Extract the complete SparePartsERP folder.
2. Keep the _internal folder beside SparePartsERP.exe.
3. Double-click SparePartsERP.exe.

On first start, open INITIAL_ADMIN_CREDENTIALS.txt for the admin login, then
sign in and change the password. Delete that credentials file after saving the
password. Keep the app folder in a location where your Windows account can
write files.

The database (db.sqlite3) and uploaded files (media) are stored beside the
application. Back them up regularly and keep backups private.

To try the app from other computers on the same trusted Wi-Fi/LAN, use the
Network URL shown by the app. Keep the server PC on and allow the app through
Windows Firewall on private networks if prompted. This local HTTP setup is for
testing only; do not expose it directly to the public internet.
